## Tegao - Japanese Word Helper | Addon
### Optional Addon: Yomitan Dictionary
Tegao: YomitanDictionary is an optional app that holds a pre-made database of Japanese word definition, able to pair with Tegao for an offline functional and plentiful dictionary lookup. Based on Yomitan's JMDict processed dictionary.

Required [Tegao](https://github.com/watashiwalds/tegao-japanesewordhelper) to be usable.

Build on collaboration with [@Wangamrt](https://github.com/Wangamrt) who processed Yomitan's released dictionary used in this addon.
